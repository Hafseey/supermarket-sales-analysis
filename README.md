
# Supermarket Sales Analysis Using Python

## Project Overview

This project analyzes supermarket sales data to identify sales patterns, customer behavior, product performance, and business trends.

The analysis was carried out using Python and focuses on data cleaning, exploratory data analysis, visualization, and extracting business insights.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains 1,000 supermarket transactions and 17 original columns, including:

- Branch
- City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Sales
- Payment
- Rating
- Gross Income
- Date
- Time

Additional columns such as Month, Day, and Hour were created during the analysis.

## Analysis Performed

The project covers:

- Data inspection and cleaning
- Missing-value analysis
- Duplicate-value checking
- Sales analysis
- Product-line analysis
- Branch analysis
- Customer analysis
- Payment-method analysis
- Monthly and daily sales trends
- Hourly sales analysis
- Customer-rating analysis
- Correlation analysis
- Pivot-table analysis
- KPI summary
- Dashboard visualization

## Key Performance Indicators

The analysis calculated:

- Total Sales
- Average Sale
- Highest Single Sale
- Total Quantity Sold
- Best Product Line
- Best Branch
- Best Sales Month
- Best Sales Day
- Peak Sales Hour

## Visualizations

The project includes visualizations for:

- Sales by Product Line
- Sales by Branch
- Monthly Sales Trend
- Sales by Payment Method
- Sales by Customer Type
- Sales by Gender
- Sales by City
- Sales by Day
- Sales by Hour
- Sales vs Rating
- Quantity vs Sales
- Sales Distribution
- Branch and Product Line Performance
- Customer Type and Product Line Performance
- Branch and Payment Method Performance

## Dashboard

A combined sales performance dashboard was created using Matplotlib.

## Conclusion

This project demonstrates the use of Python for cleaning, analyzing, visualizing, and interpreting real-world sales data.

The analysis provides insights that can help a business understand its strongest products, branches, customer groups, sales periods, and transaction patterns.
